# ATA & LTA ERP — Design, UI/UX & Typography Review

Reviewed 2026-10-19 at baseline `0c61395` (`brutalist-ui`).
**Scope:** Production React 19 frontend (`frontend/src/` and `frontend/index.html`). Excluded `erp_prototype/` entirely.

---

## 1. Executive Summary

The production ATA & LTA Accounting Firm ERP has strong functional engineering—strict RBAC permission guards, multi-entity (`ATA` / `LTA` / `ALL`) scoping, real-time CDC synchronization, RFC 7807 blocking mutation modals, and comprehensive behavioral test coverage. Visually and structurally, however, the interface inherits prototype defaults and fragmented module patterns that undermine data density, typographic hierarchy, and cross-module consistency.

## 3. Chosen Direction: Swiss Industrial Print & Achromatic Ledger

- **Invoked Style Skill:** [`industrial-brutalist-ui`](file:///home/deutz/Migration_Final-render/ata-lta-erp-brutalist-ui/.agents/skills/industrial-brutalist-ui/SKILL.md) (**§2.1 Swiss Industrial Print** archetype — committed exclusively to the high-contrast light newsprint/documentation paper substrate `#F4F4F0` with Carbon Ink `#0A0A0A` and Aviation/Hazard Red `#E61919`).
- **Invoked App-Screen Skill:** [`design-taste-frontend`](file:///home/deutz/.agents/skills/design-taste-frontend/references/app-screens.md) (`draw.mjs --app --kind finance --style achromatic-ledger --keep palette,type`, saved in [.taste-skill/direction.json](file:///home/deutz/Migration_Final-render/ata-lta-erp-brutalist-ui/.taste-skill/direction.json)).
- **Product Face & Signature Element:**
  - **Substrate:** Unbleached documentation paper (`#F4F4F0`) with crisp `#FAF9F5` / `#FFFFFF` data sheets and `#EAE8E3` recessed technical rails, partitioned by exposed `1px` and `2px solid #0A0A0A` blueprint grid lines.
  - **Typographic Polarity:** Heavy Neo-Grotesque (`Inter` 700–900 / `Archivo Black`, tight tracking `-0.03em`) for structural module titles and primary ledger sums, paired with `JetBrains Mono` (`tabular-nums`, uppercase tracking `0.06em`) for telemetry metadata, document/invoice/voucher IDs, entity stamps (`[ATA]`, `[LTA]`, `[ALL]`), and financial columns.
  - **Zero-Regression Functional Guarantee:** All routes, RBAC checks, query keys, real-time subscriptions, modals, print templates (`printDocuments.ts`, `TransmittalPrintModal`, `PrintPreviewModal`, `AgingReportTab` print block), and `data-testid` contracts remain 100% intact.
